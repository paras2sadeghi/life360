# Life360 · Revenue design concept

Interview follow-up by **Parastoo Sadeghi** ([parastoo.studio](https://parastoo.studio)).

- `/` — a redesigned Life360 landing page (mobile first), built in React + Framer Motion and bundled into one file.
- `/case-study` — five revenue experiments: insight, bet, primary metric and guardrail for each, with interactive mockups.
- `/life360-case-study.pdf` — the same case study as a 9-slide deck.
- `source/` — the React source for the landing page (`npm install && npm run dev`).
